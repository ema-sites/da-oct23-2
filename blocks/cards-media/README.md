# cards-media

Custom **cards** block. Purpose: linked topic cards with image or looping video media.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row per card: cell 1 holds an image or a link to an .mp4 video; cell 2 holds an H3, a description and a Learn more link.

No variations.
