# hero-video

Custom **hero** block. Purpose: full-bleed video hero with eyebrow, H1, pause control and scroll-down link.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 holds the background video as a link to an .mp4 (optionally plus a poster image); row 2 holds an eyebrow paragraph, the H1 and an optional in-page link (href starting with #) that becomes the scroll-down jump link.

## Supported variations

No variations.
